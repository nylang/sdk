# Nyra 中文入门教程

[English](en/README.md)

这套教程带你从第一段程序开始，逐步学会用 Nyra 写一个有多个文件的小工具。
不需要先阅读语言设计文档。第一次接触编程，可以按顺序学习；有编程经验，也建议先完成对应系统的第 00 课，统一运行环境。

## 怎么学

每次只学一课。先把完整例子运行起来，再修改一两个地方，观察结果，最后做练习。
不需要一开始记住所有关键字。

- 标为“完整程序”的代码，可以替换练习目录中的整个 `main.ny`。
- 标为“局部片段”的代码，只放进说明指定的位置，不能单独运行。
- 标为“故意写错”的代码，用来理解报错；不要和正确版本混在一起。
- 代码块中的预期输出是学习目标，不是这套文档已经执行过的测试报告。

这份公开版从 [SDK 1.0.3 安装指南](../../INSTALL.md) 起步，不需要编译器源码仓库。
课程由开发期教程整理而来；公开起步步骤按完整 SDK 的目录布局调整。
第 09 课的生态依赖须留意 [1.0.3 的 Git lock 已知问题](../../RELEASE-1.0.3.md)，
第 16、17 课保留交叉编译集成参考，所需开发期构建脚本不包含在公开 SDK 中。
本次发布没有重新执行全部例子或验证手机设备运行；预期输出不等同于验收报告。
1.0.4 的命令在课程中明确标为候选能力，不能假定 1.0.3 已提供。

完成第 00 课后，后续课程替换并保存 `playground/main.ny`，再执行这两条命令：

```sh
"$NYRAC" check "$NYRA_WORK/playground/main.ny"
"$NYRAC" run "$NYRA_WORK/playground/main.ny" \
  --out-dir "$NYRA_WORK/out/current"
```

Windows PowerShell 对应命令：

```powershell
& $env:NYRAC check "$env:NYRA_WORK/playground/main.ny"
& $env:NYRAC run "$env:NYRA_WORK/playground/main.ny" --out-dir "$env:NYRA_WORK/out/current"
```

如果课程另建了测试包或要求切换目录，就使用那一课给出的路径。
每个完整程序分别运行；不要把多个 `func main()` 合并到同一份文件。
某条构建命令报错时先停下来修复，不要继续运行上一次留下的旧可执行文件或旧库。

## 遇到问题时

先看自己系统起步课的排错步骤，再检查：

1. 当前终端是否还保留第 00 课设置的变量。
2. 修改的是不是当前编译命令指定的文件。
3. 是否把“局部片段”误当作完整程序。
4. 输出占位符是否写成 `{0}`、`{1}`。
5. 普通语句后面是否漏了 `;`。

练习代码、可执行文件和编译中间文件统一放在 `cache/learn/`，不要放进编译器源码目录。
